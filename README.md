## 🌌 关于 PageLab

**PageLab** 是一个用于收藏和展示前端视觉作品的实验仓库。

这里记录了我与 AI 一起设计、开发和探索的各种网页作品：

- 🚀 未来科技风页面
- 🎮 游戏角色展示页面
- 🪐 科幻主题 UI
- 🌈 动态交互效果
- 💎 高质量视觉实验
- 🤖 AI 辅助生成的创意作品


每一个页面都是一次关于：

> 「如果未来的网站可以这样设计？」

的探索。


---

## ✨ 项目特色


### 🎨 极致视觉设计

注重：

- 页面氛围
- 动效表现
- 光影效果
- 交互体验
- 细节打磨


让网页不仅是信息展示，更成为一种视觉作品。


---

### 🤖 AI + Frontend

PageLab 也是一次 AI 辅助开发实验。

通过 AI：

- 生成设计灵感
- 优化代码结构
- 创造复杂动画
- 探索新的交互方式


尝试让 AI 成为前端创作中的协作者。


---

### ⚡ 丰富的 Web 技术实验

项目中会不断尝试：

- HTML5
- CSS3 Animation
- JavaScript
- Canvas
- WebGL
- 响应式布局
- 现代 UI 设计


探索网页能够达到的更多可能。

# 🚀 使用方式


克隆项目：

```bash
git clone https://github.com/linkkk0/pagelab.git
```


进入目录：

```bash
cd pagelab
```


使用浏览器打开对应 HTML 文件即可查看作品。
